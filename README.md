# Коло Новин

Сайт з головними новинами світу за останні 24 години. Є версії для комп'ютера й телефона, 4 мови (українська, англійська, китайська, російська) з однаковим набором новин, темна і світла тема.

## Сайт в інтернеті

**https://eliferenkonikita-glitch.github.io/kolo-novyn/** — працює без увімкненого Mac. GitHub Actions кожні 20 хвилин збирає новини, перекладає і оновлює сайт (`.github/workflows/update.yml`). Запустити оновлення вручну: вкладка «Actions» у репозиторії → «Оновлення новин» → «Run workflow».

## Як запустити на своєму Mac (запасний варіант)

1. Двічі клікнути **«Запустити Коло Новин.command»** (або в Терміналі: `python3 server.py`).
2. Відкриється вікно Терміналу, у якому будуть адреси:
   - на цьому Mac: http://localhost:8000
   - на iPhone (та сама Wi-Fi чи точка доступу): `http://<адреса-Mac>:8000`. Точну адресу показує Термінал.
3. Щоб зупинити сайт, закрийте вікно Терміналу або натисніть Ctrl+C.

Якщо macOS спитає «Дозволити Python приймати вхідні з'єднання?», натисніть «Дозволити», інакше телефон не відкриє сайт.

На iPhone: Safari → «Поділитися» → «На екран Додому». Сайт відкриватиметься як застосунок з іконкою.

## Як це працює

- `collector/fetch_news.py` завантажує всі RSS-стрічки (видання 4 мовами) в одну спільну стрічку, залишає новини за 24 години, об'єднує однакові події з різних джерел і мов та розкладає їх по категоріях.
- **У кожній мові сайту однаковий, максимальний набір новин.** Якщо видання пише вибраною мовою, показується оригінал. Інакше показується машинний переклад Google Translate, позначений іконкою мови оригіналу; у вікні новини є кнопка «Показати оригінал».
- Якщо перекладач недоступний, новина не зникає, а показується в оригіналі з помаранчевою позначкою мови.
- Переклади зберігаються в `data/translations.json`, тому кожен текст перекладається один раз. Перший запуск триває ~1,5 хв, наступні — кілька секунд.
- `server.py` роздає сайт (дані — у стиснутому вигляді) і сам оновлює новини кожні 20 хвилин.
- Перекладач — безкоштовна неофіційна адреса Google без ключа. Google може її змінити або обмежити; тоді сайт тимчасово показуватиме оригінали.

## Що можна змінити

- Джерела: `collector/feeds.py`. Мова, під якою записане джерело, — це мова, якою воно пише.
- Слова, за якими новина потрапляє в категорію (США, Китай, Україна, Росія, Європа і Азія): `collector/keywords.py`.
- Вигляд: `assets/style.css`. Тексти інтерфейсу й логіка: `assets/app.js`.
